# Tutorial_2 · Python If / Else

Interactive CPE 1001L tutorial based on Python_If_Else_Tutorial (Fahrenheit Edition), parts 1–6.

Six lessons cover if, if/else, if/elif/else, independent if statements, nested decisions, and a Sense HAT mood light. Every lesson requires all listed input/output tests using the same code and a correct understanding answer. Lessons 1–5 use the console; lesson 6 also fills the LEDs green or blue on the simulated Sense HAT.

Submit a screenshot showing the required lesson numbers in **Lessons Successfully Completed**. The header identifies Tutorial 2. Progress survives refreshes in the same tab; use **Save progress** before closing and **Open progress** to resume. Tutorial 1 files cannot be imported. Checks are learning aids, not secure grading.

The Python runtime is bundled. Its license is in PYODIDE-LICENSE.txt. GitHub Pages serves the repository root without a build. Tutorial 1 remains separate.
